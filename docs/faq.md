# FAQ

## How do you spell the name of this game?

Public Toilet Manager, three words, each starting with a capital letter.
It is abbreviated as PTM.
The code repository of this game is called `publictoiletmanager`.

## Who made this game?

Joost van den Bogaart made Public Toilet Manager in 2006.

## Is there a cheat?

Yes. Click the customers icon, double-click the toilet paper icon,
click the soap icon, click the towels icon,
and then click the happiness icon to get € 10000.

## Where is my saved game?

The Qt version saves the game to `SaveGame.sav`
in the application data folder,
for example `~/.local/share/PublicToiletManager` on Linux
and `%APPDATA%\PublicToiletManager` on Windows.
The file format is the same as that of the original version.
